# Critérios de decisão para projetos

## Problema

Kevyn produz ideias em alta velocidade e consegue aprofundá-las rapidamente. O custo é dispersão: conceitos, empresas, produtos e sistemas passam a competir pela mesma energia antes de terem status, hipótese e próxima ação claros. Quando isso acontece, projeto e vida prática passam a disputar a mesma capacidade de cuidado.

## Peso epistemológico

- Forte para organizar a decisão prática em torno de custo, cuidado e possibilidade de teste.
- Médio para ler preferências recorrentes de Kevyn diante de projetos.
- Fraco para tratar a matriz como lei universal fora do contexto biográfico.

## Matriz de decisão

Avaliar cada projeto de 0 a 2 em:

| Critério | Pergunta |
|---|---|
| alinhamento | aproxima da vida desejada ou apenas alimenta urgência? |
| evidência | existe demanda, usuário, cliente ou dado concreto? |
| capacidade | há tempo, dinheiro e competência disponíveis agora? |
| cuidado | isso preserva sono, vínculo, rotina e saúde mental? |
| reversibilidade | é possível testar pequeno e abandonar sem grande perda? |
| aprendizagem | o teste produz conhecimento útil mesmo se falhar? |
| manutenção | quem sustentará o projeto depois da criação? |

## Regra de ativação

Um projeto só entra em “ativo” quando possui resultado esperado, próximo marco, limite de esforço, critério de pausa e custo de cuidado aceitável. Os demais vão para [[Estacionamento de ideias]].

## Revisão

Usar junto de [[Kanban de projetos]], [[Portfolio de projetos]], [[Cuidado de si]] e [[Vontade SMART]]. Status antigo não deve ser presumido como atual.

A [[Trilha de revisao de projetos]] usa estes critérios para revisar o portfólio inteiro sem perder o vínculo entre decisão, custo e capacidade.

## O que este critério revela sobre Kevyn

- Kevyn decide melhor quando o projeto sai do campo da ideia e entra em teste pequeno.
- A sustentabilidade pessoal conta tanto quanto a oportunidade externa.
- O custo de manutenção não é detalhe; é parte do próprio critério.
- A revisão frequente protege Kevyn de transformar impulso em compromisso rígido.
- Organização do conhecimento, cuidado e trabalho precisam caminhar juntos para a decisão permanecer útil.
