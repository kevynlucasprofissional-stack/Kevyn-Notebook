# Decisoes e compromissos

## Síntese

Esta nota registra o que já foi escolhido e o que ainda precisa de revisão. A distinção central é entre reflexão, decisão e compromisso observável.

## Peso epistemológico

- Forte para registrar escolhas explícitas e compromissos datados.
- Médio para interpretar direção de vida e prioridades.
- Fraco para inferir constância comportamental a partir de uma única decisão.

## Distinção

Uma reflexão não é uma decisão. Uma decisão só entra aqui quando contém escolha, data, razão, consequência e condição de revisão.

## Modelo

| Campo | Conteúdo |
|---|---|
| decisão | o que foi escolhido |
| data | quando |
| evidência | em que dados se baseia |
| renúncia | o que deixa de ser feito |
| próximo passo | ação observável |
| revisão | data ou gatilho |

## Regra de integridade

Não retroagir decisões para fazer a história parecer linear. Mudanças de opinião são dados relevantes e devem ser registradas como revisão, não apagadas.

- Kevyn se beneficia de compromissos pequenos, datados e revisáveis.

- A revisão frequente protege contra promessa excessiva e leitura inflada de progresso.
- O vault só ganha valor aqui quando compromisso, custo e próximo passo ficam visíveis ao mesmo tempo.
