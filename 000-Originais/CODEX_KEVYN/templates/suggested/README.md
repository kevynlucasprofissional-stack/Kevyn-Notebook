# Suggested Templates

Este pacote e uma camada futura leve para conviver com o legado.

Uso sugerido:

- aplicar em notas novas
- usar em notas antigas apenas quando houver revisao manual
- adaptar localmente dentro de cada sub-vault quando fizer sentido
- manter as convencoes no nivel do vault principal, sem impor retrofit aos sub-vaults

Arquivos incluidos:

- `00-inbox-capture.md`
- `01-note-default.md`
- `02-hub-moc.md`
- `03-area-home.md`
- `04-archive-record.md`
- `05-review-note.md`
- `CONVENTIONS.md`

Padrao comum:

- frontmatter minimo
- foco em navegabilidade
- pouco acoplamento com a estrutura existente
- foco principal no futuro, nao no legado inteiro

Observacao:

- os nomes podem ser ajustados para o plugin de templates que voce usar
- o conteudo e propositalmente curto para reduzir manutencao
- `_staging/` funciona como inbox e fila de triagem; os templates assumem esse fluxo
