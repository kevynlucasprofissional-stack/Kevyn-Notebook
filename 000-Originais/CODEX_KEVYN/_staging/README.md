# Staging

Zona operacional leve para novas entradas, triagem e manifestos temporarios.

## Regras

- Capturas novas entram primeiro em `inbox/` quando ainda nao houver destino claro.
- Material em analise fica em `review/`.
- Listas temporarias, exports e manifestos humanos ficam em `manifests/`.
- Nada aqui exige reorganizacao retroativa do vault.
- Se uma nota ganhar contexto suficiente, ela pode ser promovida manualmente para uma area viva.
