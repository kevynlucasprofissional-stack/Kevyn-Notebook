# O Mantra Pré-Espetáculo de Thurston

## Conceito
O 'Mantra Pré-Espetáculo' é uma técnica de 'priming' emocional, uma forma de auto-sugestão usada para intencionalmente induzir um estado mental e emocional desejado antes de uma performance. Ao repetir a frase 'Amo meu público!', Thurston não estava apenas expressando um sentimento, mas ativamente cultivando-o. Este ritual mental serve para focar a mente no sentimento de conexão e serviço, suprimindo o nervosismo, o ego ou o cinismo. É a prática de usar a linguagem interna para calibrar a emoção externa que se deseja projetar.

ELI5: Antes de entrar no palco, o mágico ficava repetindo para si mesmo 'eu amo essas pessoas', como se estivesse se enchendo de um 'poder de amizade' para que o show fosse o melhor possível.

## Importância
Para a mente sistemática de Kevyn, esta é uma ferramenta de 'engenharia emocional' extremamente prática. Ele, que luta com a ansiedade social e a persona do 'Professor Arrogante', pode usar mantras como este para 'programar' seu estado antes de interações cruciais. É um método que apela à sua natureza de 'Mago', que usa palavras de poder (encantamentos) para alterar a realidade — neste caso, sua própria realidade interna. É um ritual simples para mudar do modo 'Hoor' (guerra) para o modo 'ELAMOR' (conexão).

## Insight
Este é o ritual prático que coloca em ação o [[O Interesse Genuíno no Público]]. É uma aplicação do princípio de [[Ação e Sensação Andam Juntas (William James)]], onde a fala (ação) regula o sentimento. Esse conceito pode ser usado para servir à comunidade da seguinte forma: Kevyn pode ensinar essa técnica a pessoas que têm medo de falar em público, sugerindo que elas criem seu próprio mantra pré-apresentação (ex: 'Estou aqui para ajudar', 'Eu conheço este assunto').
