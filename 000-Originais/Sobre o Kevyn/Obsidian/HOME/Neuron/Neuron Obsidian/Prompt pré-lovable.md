## CONTEXTO DO PRODUTO

O **Neuron** é um SaaS de aprendizado gamificado sobre Inteligência Artificial.

Porém, para o MVP, não vamos começar com várias rotas de IA.  
Vamos começar com **uma única trilha inicial**:

**Trilha de Engenharia de Prompt**

Essa trilha deve ser baseada principalmente no livro:

**“The Art of Asking ChatGPT for High-Quality Answers: A Complete Guide to Prompt Engineering Techniques (Ibrahim John)”**

Esse livro deve ser tratado como a **principal fonte de verdade** para montar a trilha de Prompt Engineering.

- módulos
- lições
- progressão didática
- ordem pedagógica
- conceitos
- exemplos

- agrupamento lógico dos temas

## ESTRUTURA TÉCNICA QUE DEVE SER RESPEITADA

Considere o seguinte modelo funcional do sistema:

### Regras do sistema
- usuários podem criar conta e fazer login
- todo usuário do MVP é um aluno
- cada usuário possui um perfil de aluno
- o dashboard mostra trilhas disponíveis
- no MVP só existe uma trilha principal: Engenharia de Prompt
- trilhas possuem módulos
- módulos possuem lições
- lições possuem conteúdo, exercício e feedback
- o progresso deve ser salvo por usuário
- o usuário pode continuar de onde parou
- módulos podem ser desbloqueados conforme avanço
- free vê anúncios
- premium não vê anúncios
- o usuário pode assinar o premium

### Permissões
Aluno:
- fazer login
- criar conta
- editar próprio perfil
- acessar dashboard
- iniciar trilha
- responder exercícios
- acompanhar progresso
- assinar premium

Admin:
- criar trilhas
- editar trilhas
- criar módulos
- editar módulos
- criar lições
- editar lições

### Integrações
Considere que o sistema pode usar:
- Supabase
- Stripe
- serviço de anúncios
- provedor de e-mail
- IA para feedback
- analytics

### Segurança
Considere no raciocínio:
- autenticação obrigatória para áreas internas
- usuário só edita o próprio perfil
- progresso pertence ao usuário autenticado
- assinatura só é validada por backend seguro
- conteúdo administrativo não é editável por aluno

## COMO VOCÊ DEVE PENSAR A TRILHA DE PROMPT ENGINEERING

Use o livro “The Art of Asking ChatGPT for High-Quality Answers” como base principal.

Transforme o conteúdo do livro em uma experiência de aprendizado moderna e progressiva.

A trilha não deve ser uma simples cópia dos capítulos.
Ela deve ser reorganizada pedagogicamente para um SaaS gamificado.

Você deve identificar, organizar e distribuir os temas em módulos e lições com lógica de progressão, por exemplo:

- fundamentos de prompt
- estrutura de um bom prompt
- instruction prompting
- role prompting
- standard prompts
- zero-shot, one-shot, few-shot
- seed-word prompting
- self-consistency
- knowledge generation
- knowledge integration
- summarization
- question-answering
- dialogue prompts
- controlled generation
- clustering
- sentiment analysis
- text classification
- text generation
- curriculum learning
- reinforcement learning prompts
- etc.

Mas não apenas listar.
Quero que você distribua isso em módulos com:

- sequência didática boa
- curva de aprendizagem saudável
- aplicação prática
- exercícios progressivos
- sensação de evolução real
