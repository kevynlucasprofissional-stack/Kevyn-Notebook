# Zettelkasten: Estratégia de Etiquetas

## Conceito
O sistema de etiquetas visa criar conexões lógicas, não apenas categorizar. As categorias principais são: #tarefas (ação prática), #aprendizado (estudo/digestão), #informativo (dado factual útil), #fugaz (ideias cruas/insights passageiros), #permanente (conteúdo refinado/princípios) e # flashcards (memorização). Recomenda-se o uso de múltiplas etiquetas apenas se criarem pontes lógicas (ex: aprendizado + flashcards).

## Importância
Evita o caos no gerenciamento de conhecimento e define o 'estado de maturidade' de cada nota.

## Insight
Isso se conecta com [[Gestão de Conhecimento vs Tempo]] porque separa claramente o que é arquivo de referência (#permanente) do que é ação (#tarefas).
