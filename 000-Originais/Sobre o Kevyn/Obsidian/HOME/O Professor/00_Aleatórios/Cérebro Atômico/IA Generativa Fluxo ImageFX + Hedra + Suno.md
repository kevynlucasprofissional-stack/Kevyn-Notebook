# IA Generativa: Fluxo ImageFX + Hedra + Suno

## Conceito
Um fluxo de trabalho poderoso para criação audiovisual com IA consiste em: 1. Usar **Suno** para gerar a música completa. 2. Usar **ImageFX** (Google) para criar personagens e cenários consistentes. 3. Usar **Hedra** para animar a imagem estática fazendo 'lip sync' (sincronia labial) com a letra da música gerada.

## Importância
Permite a criação de videoclipes complexos e narrativos por uma única pessoa a custo quase zero.

## Insight
Isso se conecta com [[Hoor Digital: Visão]] pois materializa a visão de 'um estúdio na palma da mão'.
