# Vertex Map no Cinema 4D

## Conceito
Vertex Maps permitem pintar pesos (valores de 0 a 100%) nos vértices de um objeto 3D. Esses mapas podem ser usados para controlar a influência de deformadores, misturar materiais (texturas) ou guiar simulações físicas (como soft body ou cloth). É uma ferramenta essencial para efeitos procedurais e orgânicos.

## Importância
Permite controle granular sobre onde os efeitos acontecem em um modelo 3D.

## Insight
Isso se conecta com [[Displacer]] porque um Vertex Map pode ser usado como máscara para limitar onde o Displacer afeta o objeto.
