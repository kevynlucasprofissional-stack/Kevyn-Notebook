# Design: Grade (Grid)

## Conceito
O Grid (Grade) é a estrutura invisível que organiza os elementos no espaço de design. É crucial para alinhamento, consistência e hierarquia visual. 'Que Grid é uma coisa bem importante' é um ensinamento central de ZRD.

## Importância
Diferencia o design amador (caótico) do profissional (estruturado).

## Insight
Isso se conecta com [[Kevyn Lucas: Arquétipo Mago]] pois o Grid é a 'ordem' que o Arquiteto (Kevyn) impõe ao caos criativo.
