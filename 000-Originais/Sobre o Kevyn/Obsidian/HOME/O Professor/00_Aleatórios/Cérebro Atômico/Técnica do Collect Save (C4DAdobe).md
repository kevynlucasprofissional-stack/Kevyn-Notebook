# Técnica do Collect Save (C4D/Adobe)

## Conceito
O 'Collect Save' (ou Package no Illustrator/InDesign) é uma função crítica em softwares criativos que salva o arquivo de projeto junto com *todos* os ativos externos dependentes (texturas, fontes, áudios) em uma única pasta. Isso resolve o problema de 'arquivos offline' ou links quebrados ao mover o projeto entre computadores ou fazer backup. No Cinema 4D, é acessado via 'Save Project with assets...'.

## Importância
Garante a integridade do projeto a longo prazo e facilita a colaboração em equipe. Sem isso, o arquivo do projeto é apenas um esqueleto sem pele.

## Insight
Isso se conecta metaforicamente com [[La Loba (A Mulher dos Ossos)]] (recuperação da alma), pois o Collect Save 'recolhe os ossos' (estrutura) e a 'carne' (ativos) para manter a vida do projeto intacta.

### Conexões:
- [[La Loba (A Mulher dos Ossos)]]

## Ação
- [ ] Sempre executar 'Save Project with assets' antes de arquivar qualquer projeto 3D ou de vídeo.
