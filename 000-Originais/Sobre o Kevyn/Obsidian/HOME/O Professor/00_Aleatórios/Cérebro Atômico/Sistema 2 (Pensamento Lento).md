# Sistema 2 (Pensamento Lento)

## Conceito
Conceito de Daniel Kahneman. O Sistema 2 é o modo de pensamento alocativo, lento, sequencial, lógico e que exige esforço consciente. É responsável por cálculos complexos, autocontrole e monitoramento do comportamento. Ao contrário do Sistema 1 (rápido, intuitivo, automático), o Sistema 2 é 'preguiçoso' e só é ativado quando necessário. Na arquitetura de Clarissa Pinkola Estés, ela valoriza a *intuição* (Sistema 1 refinado) acima da lógica fria, mas no contexto de [[Orquestração Modular de Prompts (Python)]], usamos o código para *forçar* a IA a operar em Sistema 2.

## Importância
Essencial para evitar vieses cognitivos (como WYSIATI). A maioria dos erros de julgamento ocorre quando confiamos no Sistema 1 para problemas que exigem o Sistema 2.

## Insight
Isso se conecta com [[Orquestração Modular de Prompts (Python)]] pois o script obriga a IA a parar, ler, processar e escrever passo-a-passo, simulando artificialmente um Sistema 2.
