==================================================
4. NOTIFICAÇÕES DO CHAT DA ANÁLISE
==================================================

Problema atual:
- O chat da análise continua sem enviar notificações para os outros usuários do mesmo laboratório

Implementação correta:
- Sempre que um usuário enviar uma mensagem no chat da análise:
  - criar notificação para os outros usuários do mesmo laboratório
  - não notificar o remetente
- Essas notificações devem aparecer na Caixa de Entrada
- Quando a mensagem/notificação for aberta, deve deixar de aparecer como não lida
- Se possível, atualizar em tempo real

Requisitos:
- relacionar notificação ao laboratório
- relacionar notificação à análise
- relacionar notificação à mensagem enviada
- status read/unread
- contador de não lidas, se o sistema já tiver esse padrão

Critério de aceite:
- usuário A envia mensagem
- usuário B do mesmo laboratório recebe notificação
- ao abrir, a notificação é marcada como lida
