## Dataview
![[Dataview.svg]]

Este é um Plug-in Poderoso que transforma o seu cofre em um banco de dados, há várias oportunidades de transformar isto em negócio e pode te ajudar a criar aquele banco de dados não linear no qual sonhou.

O ChatGPT consegue escrever scripts para Dataview, posso usá-lo para meus propósitos, eliminando a necessidade de estudar e ficar fluente na linguagem Querry ou DataviewJS para só então conseguir conseguir consultar dados das minhas notas através deste plug-in.
### Table
Cria uma tabela.
### List
Cria uma lista
### Task
Reúne as tarefas
### Tags
Mostra as tags utilizadas nas notas.
### Propriedades
Permite puxar dados das propriedades definidas nos arquivos
### AS
Usado para **renomear colunas** ou propriedades na saída.  
Exemplo: `status AS Situação`.
### From
Define de onde os dados serão extraídos, geralmente um caminho, pasta ou tag. 
Exemplo: `FROM "Projetos"`.
### AND
Exibe dados que carregam duas variáveis. 
### OR
Exibe dados que carregam um variável ou outra.
### -
Ao utilizar o negativo atrás de uma variável, será exibido todos os dados que NÃO contém aquela variável.
