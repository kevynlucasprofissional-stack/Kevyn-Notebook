É necessário sinalizar para o plug-in que uma certa nota tem cartões de repetição espaçada. Para isso use a tag "flashcards".

Use {{chaves}} para criar cartões de omissão.

Use ;; entre duas frases para criar cartões de frente e verso, onde a frente tem uma pergunta e o verso a resposta.

Use § para criar cartões multilinhas.

Lembre-se de configurar para preencher toda a tela, assim ficará acessível também no Mobile.
