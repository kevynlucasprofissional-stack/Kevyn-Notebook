É um plugin pago. Deve ser instalado dentro da pasta "ScriptUI Panels", basta copiar e colar lá.

O Duik, que é um concorrente do Rubberhose, é um software de rigging bem moderno e sofisticado. Tão falando bem dele, talvez seja melhor.

O Rubberhose cria três camadas que já é todo o plugin, a de base, a de star e a de end. E isso já é um rigging, o objetivo é usar isto para animar personagens. Geralmente este rigging do rubberhose é usado para controlar os movimentos do personagem, como um esqueleto virtual, e a escolha deste rigging influenciar a estética do personagem é totalmente sua.

Para ajustar a estética do elemento, ajuste pela camada de base. É possível, usando o recurso de "Adicionar", ir criando vários elementos dentro de uma mesma base, como por exemplo, criar o braço e a manga do personagem na mesma base.

É possível copiar e colar as propriedades de uma base na outra usando os botões no painel do plugin.

Segurar o Alt e clicar no ícone com um + no painel do plugin, você duplica o grupo da base selecionada.

É possível desativar a visualização dos controladores no painel de parâmetros do plugin.

O Auto Flop faz com que a curva mude de direção automaticamente. É possível tornar visível a área do Auto Flop e editar ela pela Viewport, assim como é possível animar manualmente a mudança de direção pelo Bend Direction.

Objetos parenteados a controladores rotacionam automaticamente, seguindo a direção do movimento do controlador. Se o controlador é rotacionado, então o objeto parenteado também é. Dá para tornar a rotação do objeto parenteado como estática, assim ele não rotacionará mais de acordo com o movimento do controlador, basta ativar "Freeze Rotation", mas não é muito prático, recurso para situações específicas.

Adicionando Strokes e Trim Paths nas bases dá para fazer muitas coisas, incluindo mangas, meias, sombras e etc...
