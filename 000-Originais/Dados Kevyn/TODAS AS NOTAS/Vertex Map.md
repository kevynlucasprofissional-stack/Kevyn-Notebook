Para habilitar, clique com o botão direito no modelo alvo e vá em "Other tags > Vertex Map". Habilite o Use Field, para controlar o efeito através de um campo de efeito.
Coloque o Freeze em modo Grow.
Sempre ajuste a velocidade de expansão do vertex map, se necessário coloque um efeito de delay.
Decida se usará ou não o delay, tudo irá depender de sua necessidade.

>Nunca importe um Vertex Map direto da janela de objetos para um node editor de material, isso vai crashar o C4D.
