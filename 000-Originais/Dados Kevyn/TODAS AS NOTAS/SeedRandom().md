Define um valor para os movimentos aleatórios. Esse valor irá padronizar os movimentos de acordo com um número.
Este número pode ser usado para tornar idênticos os movimentos de Wiggle em dois modelos separados.
Adicionado no editor de expressões antes das expressões de movimentação.
Geralmente, para a seedRandom() funcionar corretamente, é necessário que ela esteja na primeira linha.
A seedRandom() deve ter dois parâmetros, o primeiro é a semente, que é representado por um número, a segunda é o estado da expressão, que para ser definido como habilitado deve ser "True"
 >Exemplo: seedrandom(2, true)
