# **ETAPA 02: Qualificação**
Qual o perfil do cliente?
O cliente sabe que tem um problema?
A solução é útil para resolver o problema do cliente?
O cliente entende o valor dessa solução para o problema dele?
Segundo o perfil do cliente, qual o orçamento máximo provável para investir na solução?
O cliente tem poder de decisão?
Quanto tempo vai levar para o cliente decidir?
Quais as consequências de adotar a solução tardiamente?
Quais metas o cliente precisa e quer atingir? Ele tem um plano para isso?
Quais as dificuldades que precisam ser superadas para a decisão ser tomada?
É possível gerar interesse em demonstrar como a solução irá gerar uma realidade nova e melhor?

# **ETAPA 03: Problema**
O perfil do cliente é analisado e são levantados todos os pontos de melhoria, aqui o método "Design em 12 passos" do Munari pode ser aplicado. Esta parte pode ser feita previamente ou em uma reunião com o cliente para um mapeamento dos pontos de melhoria com maior precisão.

Livro: Das coisas nascem coisas

# **ETAPA 04: Solução**
Aqui será apresentado para o cliente a solução que temos para o problema dele. Deve ser feito de acordo com todas as informações levantadas nos passos anteriores em uma reunião. Carisma e Persuasão aqui será a melhor estrátegia.

Um bom início de apresentação é "[Nome], se ao final desta reunião você realmente entender que essa solução é para você e que ela vai resolver o seu problema, você está disposto a tomar a decisão de compra hoje mesmo?"

Use sempre "Você entendeu, [nome]?" ou "Faz sentido para você, [nome]?"

# **ETAPA 05: Monitoramento**
Aqui é onde mantemos contato constante com o cliente cuja solução já foi apresentada com o objetivo de guiá-lo a decisão de fechamento. Para descobrir objeções ocultas e engatilhar uma negociação use:

"[nome], de zero a dez, qual o seu nível de interesse em adquirir esse produto? - {Espere resposta} - E o que a nós podemos fazer para transformar esse [número] em um dez?"

"[Nome], existe alguma razão para você não adotar nossa solução hoje mesmo?"

Tenho que falar com a pessoa com poder de decisão...
"[Nome], baseado no que você conhece da [pessoa com poder de decisão], o que você acha que ela dirá quando você falar com ela sobre nossa solução?"

Vou pensar...
"[Nome], você já perdeu alguma oportunidade por demorar muito para decidir e a oportunidade passar? - {Espere resposta} - Não é horrível esse sentimento?"
ou
"[Nome], pela nossa experiência, quando um cliente diz que precisa pensar, geralmente, ou esse cliente está pesquisando outros fornecedores ou há algum incômodo com relação ao preço ou ainda há dúvidas se a solução realmente vai servir para ele. Qual dessas três opções está impedindo você de tomar a decisão?"

# **ETAPA 06: Negociação**
O cliente em algum momento levantará objeções, nesta etapa é necessário ver além e contornar as objeções do cliente. Uma objeção clássica é:

Está caro...
"[Nome], você está pensando no custo de adquirir nossa solução, mas você deveria esta se preocupando com o custo de não adquirir!"
ou
"[Nome], além do custo, existe algum outro motivo para você não comprar nossa solução?"
ou
"[Nome], você gostaria de discutir as condições de pagamento?"
ou
"[Nome], se eu te mostrar como esse produto, na verdade, vai economizar o seu dinheiro ao invés de gastar o seu dinheiro, você fecharia conosco imediatamente?"
ou
"[Nome], de fato, nós não somos a opção mais barata. Deixe-me explicar porque."
ou
"[Nome], deixe-me entender uma coisa: O que nós estamos avaliando aqui é uma solução de menor preço ou de melhor qualidade?"

# **ETAPA 07: Venda**
A troca é realizada, o pix cai na conta e a solução é entregue para o cliente. O grande segredo nessa etapa é entregar uma solução de qualidade para o cliente. Todo o resto será inútil se esta etapa não for realizada com excelência.

# **ETAPA 08: Interação**
Aqui nós faremos o cliente sentir que a troca realizada foi algo bom e memóravel realizando uma interação pública personalizada para este cliente. Alguns métodos são:

Pedir um feedback para o cliente e postar no feed.
Tirar uma foto com o cliente e postar.
Gravar um vídeo interessante e humorado enaltecendo a parceria estabelecida e postar.
Criar um meme compartilhavél e postar.
Postar um storie interativo sobre a parceria, envolvendo mais pessoas no movimento.
Criar uma animação curta que mostre a história da parceria.
Crie um post no estilo "Antes e Depois"
Envie um Email personalizado agradecendo o cliente.

# **ETAPA 09: Fidelização**
Oferecer um clube de benefícios por ser cliente da solução.
Oferecer um desconto na segunda compra.
Patrocinar um sorteio ou campanha para o cliente.
Envie um kit de agradecimento para o cliente

# **ETAPA 10: Presença**
Aqui é encaixado o investimento em prospecção, mas agora com o novo cliente em vista, sempre que possível, encaminhado para o cliente no particular para ver a postagem.
Não se deve perturbar o cliente com mensagens, pois ele é bem ocupado, contudo nunca deixe que a empresa perca sua força na mente do cliente.

Resumindo: Lembrar a cartela de clientes que estamos ativos e com a agenda aberta.

# **ETAPA 11: Oportunidade**
Promover eventos entre os clientes e oferecer benefícios para quem convidar um empreendedor para assistir.
Programa de recompensa por indicação.
Fazer uma pesquisa para coletar feedback e dados do tipo "Qual a chance de nos recomendar para um amigo?"

# **ETAPA 12: Indicação**
E, após todos os passos anteriores uma pessoa que não conhecia a empresa recomenda ela para um próximo.
