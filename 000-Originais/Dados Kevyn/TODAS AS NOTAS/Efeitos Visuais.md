O Duik é gratuito, melhor que o Rubberhose. Ele precisa ser instalado na pasta ScriptUI Panels. Caso ele não esteja funcionando, tente marcar em "Preferências > Geral" a caixa "Allow Scripts to Write Files and Acess Network".

Região de Interesse é uma opção localizada na janela de visualização de composição. Ao usar ela é possível definir uma área onde o trabalho está sendo feito. Ao se definir a área, também é possível cortar a composição no formato da Região de interesse, essa opção está disponível no menu de composição.
