Shift + C: Abre pesquisa de comandos (Commander)
	**PSR**: Retorna o objeto para as coordenadas de origem
	**Transfer**: Transfere um modelo para um ponto específico
	**Emitter**: Cria um gerador de partículas personalizável.
	**Helix**: Cria uma espiral primitiva spline
	**Camera**: Cria uma câmera.
	**Stage**: Uma ferramenta de troca de câmera automática.
	**Voronoi Fracture**: Fratura o modelo em vários pedaços.
	**Cloner**: Clona modelos.
	**Displacer**: Deforma modelos que ele for filho.
	**Random**: É um efeito randomizador.
	**Remesh**: Serve para diminuir a quantidade de polígonos de um modelo, alterando o mínimo possível do formato do modelo.
	**Null**: Cria um objeto nulo.

R: Ferramenta de rotação
T: Ferramenta de escala
C: Tornar objeto editável com malha (Transforma primitivas em editáveis)
M: Abre o menu de Mesh
M~E: Polygon Pen.
U~A: Align Normals
U: Menu de chaves
F: Vai para o Frame anterior
Shift + F: Vai para o primeiro frame.
Ctrl + F: Vai para o Keyframe anterior
G: Vai para o próximo frame.
Shift + G: Vai para o último frame.
Ctrl + G: Vai para o próximo keyframe.
Duplo clique na janela do material manager: cria um material padrão.
M~B, B: Bridge
D: Extrude
Shift + F2: Material manager (Gerenciamento de material, textura, etc...)
I: Extrude Inner
Ctrl + (Click num Keyframe da janela de propriedades): Adiciona, ou seja, anima esse keyframe na timeline.
Ctrl + (Click em um keyframe): Anima ele.
Alt + (Click no cloner através do menu Mograph com um modelo selecionado): Aplica o cloner sem resetar a PSR (Posição, Scale, Rotation), ou seja, mantém o modelo no mesmo lugar, mas agora com o cloner aplicado.
K~L: Loop Path Cut
V: Abre menu de utilidades úteis, utilize sem moderação.
Click no Scroll: Mostra todos os painéis.

	- Tanto esta, quanto o Alto + O dão zoom no objeto selecionado com a câmera quanto com o observador.

	Shift - Quebra a simetria da curva ao editar nós de Spline.

Shift + F2: Abre o Material Manager
