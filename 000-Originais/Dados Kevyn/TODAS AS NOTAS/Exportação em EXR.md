Esta é uma configuração do Octane, não sei se dá para fazer o mesmo com outros renderizadores.
Basicamente é sobre diferentes modos de render para diferentes necessidades. No Octane, estes diferentes modos de render estarão disponíveis no painel "Render AOV Group", nas configurações de renderização.
Dá para renderizar apenas o glow, apenas a luz, apenas o difuso, e como material ID, que ele gera uma cor sólida para cada textura e modelo diferente na cena.
Renderizar em material ID é útil para situações em que será necessário fazer algum ajuste em uma parte específica do projeto.
