Sempre antes de começar uma edição, crie na janela projeto a sequência em que a edição irá ficar armazenada, é uma maneira de manter uma organização de projeto mais profissional, porém, também é válido criar sequências com um modelo, só não é tão organizado. Caso um modelo seja arrastado direto para a timeline, uma sequência com o nome do modelo será criada e ali será salvo a edição feita posteriormente.
