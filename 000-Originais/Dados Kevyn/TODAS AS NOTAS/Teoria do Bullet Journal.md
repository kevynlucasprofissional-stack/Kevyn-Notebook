Para criar um bullet journal eficiente, primeiro **defina seus objetivos a longo prazo**.

[[Pilares para definir objetivos a longo prazo]]

Depois quebre o objetivo em ciclos de 5 anos, 1 ano, 1 mês, 1 semana e 1 dia.

Para isto dar certo, é necessário sempre revisar. Para conseguir encontrar novamente o caminho, é necessário sempre olhar para a direita, para os pontos fixos que você colocou como metas no tempo. **Revisar pelo menos uma vez na semana é essencial.**

O seu bullet journal deve estar sempre alinhado com as tarefas que você tem que fazer, com os eventos que são importantes e quais são as tarefas recorrentes que você deve cumprir.
