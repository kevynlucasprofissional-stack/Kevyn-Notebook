Sempre use o renderizador dos materiais que usou no projeto.
Se usou materiais nativos do Cinema 4D, use o renderizado do C4D.
Se usou materias do corona, use o renderizador do corona.
Se usou materiais do Octane, use o renderizador do Octane.
É recomendável ativar o Anti-Aliasing na melhor qualidade.

>Sempre personalize as configurações do seu render em "Render > Render Settings"

É recomendado os formatos: Tiff, Png Sequence ou MP4.
AVI também é um opção, mas a última.

Em output você pode definir o tamanho no qual o vídeo será renderizado, o FPS, a duração do vídeo, qual parte do projeto será renderizada, ou se renderizará apenas o frame atual. 

>**SEMPRE SALVE ANTES DE RENDERIZAR**

Geralmente o primeiro frame é sempre o mais demorado para renderizar.
