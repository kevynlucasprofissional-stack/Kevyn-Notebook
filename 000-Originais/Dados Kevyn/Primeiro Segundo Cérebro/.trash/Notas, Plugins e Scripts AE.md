### **Script: Motion V4
Muito utilizado por vários Motion Designers por ser rico em várias funções em uma única janela: controlar as curvas do Graph Editor, Renomear Layer com increment, ajustar o Anchor Point de várias Layers ao mesmo tempo faz o Overshoot de animações, permite linkar 2 Layers com uma linha e várias outras opções. Um dos melhores.
É possível criar grupos rápidos, e ativar o foco, onde apenas uma camada ou grupo de camadas serão visualizáveis, e isso é parecido com o modo de isolar.
A ferramenta de Animo consegue controlar vários keyframes ao mesmo tempo.
A Blend suaviza animações.
A break quebra vetores unidos em várias camadas (Shape layers e arquivos illustrator).
O Burst é uma ferramenta que cria um animação rápida flat de explosão.
Clone duplica os keyframes selecionados, se clicar segurando alt, ele duplica invertido.
O Delay cria um atraso entre várias animações selecionadas.
Dynamics é tipo um wiggle mais refinado.
Echo cria um rastro, é parecido com o efeito, mas esse tem mais parâmetros personalizáveis.
Excite é uma efeito de movimento, bem interessante.
Falloff é tipo um field, quando ele se aproxima de um objeto ele ativa uma transformação pré-estabelecida. Basta selecionar o que vai transformar, aplicar o falloff e movimentar para cima de um objeto e tcharam, a mágica acontece.
Flip espelha.
Jump parece a expressão bounce.
Null cria um null com anchor point centralizado.
Orbit faz um objeto orbitar o outro.
Spin faz o objeto rotacionar eternamente.
Parente faz um pareamento de acordo com a seleção das camadas, sendo o último o pai.
Pinplus cria nulos parenteados aos pinos.
Rename é uma ferramenta de renomeação.
Reverse inverte a ordem das camadas, as de cima vão para baixo e as de baixo vem para cima.
Sort serve para organizar os arquivos do projeto.
Stare serve para fazer com que um objeto fique "encarando" um outro.
Text Break separa os caracteres de uma camada de texto em várias camadas, uma para cada caractere.
Texture é um pack de texturas rápidas e personalizáveis.
Tracer é uma ferramenta que facilita trabalhar com caminhos e traçados, usando o caminho de posição animado de uma camada.
Trasher apaga animações e expressões aplicadas com o Motion V4
Grab facilita selecionar o mesmo parâmetros de várias camadas ao mesmo tempo, basta selecionar as camadas alvos, e selecionar um parâmetro de uma cada e clicar no grab, assim ele selecionará aquele mesmo parâmetro de todas as camadas.
Trim é igual ao efeito trim path, ou traçado,
Vector cria uma linha entre objetos selecionados. Se aplica-se ele entre 4 objetos, se cria uma animação parecia com um triângulo.
Vignete cria uma vinheta.
Wrap cria um efeito líquido. Fazendo um shape ficar com um rastro mole.
