# Playbook para Construção de Cofres no Obsidian

Este pacote transforma a experiência de construção do cofre **Filosofia Pós-Nietzsche** em um método reutilizável para orientar uma IA a planejar, produzir, conectar, auditar e entregar cofres completos sobre qualquer tema.

1. [[Playbook-Construcao-de-Cofres-no-Obsidian]] — manual principal.
2. [[Anexos/Estudo-de-Caso-Vault-Pos-Nietzsche]] — auditoria do projeto usado como estudo de caso.
3. [[Anexos/Modelos-YAML-e-Notas]] — contratos de dados e modelos por tipo de nota.
4. [[Anexos/Biblioteca-Dataview-Bases-e-Consultas]] — consultas reutilizáveis.
5. [[Anexos/Checklists-de-Producao-Auditoria-e-Entrega]] — controle operacional.
6. [[Prompt-Mestre-IA-para-Criar-Cofres]] — prompt reutilizável para solicitar um novo cofre.
7. [[Referencias-e-Fontes]] — documentação técnica e metodológica consultada.

## O que este pacote entrega

- método de interpretação e delimitação de qualquer tema;
- arquitetura universal de pastas e notas;
- ontologia e vocabulário controlado de relações;
- padrões de nomenclatura e YAML;
- algoritmo para criação de links semanticamente justificáveis;
- MOCs manuais e vistas dinâmicas;
- critérios para usar recursos nativos, Dataview, DataviewJS, Bases e Templater;
- planejamento do Graph View e de arquivos Canvas;
- critérios de densidade, profundidade, evidência e originalidade;
- auditorias técnicas, semânticas, bibliográficas, visuais e editoriais;
- protocolo de empacotamento em `.zip` e validação pós-extração;
- prompt mestre pronto para reutilização.

## Princípio central

> Um cofre excelente não é o que contém mais notas nem o que produz o grafo mais bonito. É o que permite ao usuário compreender por que cada nota existe, de onde cada afirmação veio, o que cada ligação significa e quais limitações permanecem abertas.

## Escopo desta versão

Este é um manual de produção. Ele não cria um novo cofre temático. O estudo de caso filosófico é usado para extrair padrões, erros e critérios que possam ser generalizados.
