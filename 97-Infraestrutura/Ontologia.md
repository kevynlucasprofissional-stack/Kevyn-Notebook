# Ontologia do vault

## Tipos principais

| Tipo | Função |
|---|---|
| `pessoa` | representar Kevyn ou alguém relevante para sua trajetória |
| `tema_pessoal` | organizar um domínio persistente da vida |
| `qualidade` | força observada ou relatada |
| `dificuldade` | obstáculo ou padrão problemático |
| `evento` | ocorrência localizada no tempo |
| `projeto` | iniciativa com objetivo e estado |
| `organizacao` | empresa, grupo ou instituição |
| `sonho` | registro onírico ou imaginação ativa |
| `pratica` | rotina, método ou protocolo |
| `hipotese` | interpretação provisória |
| `fonte` | registro de proveniência |
| `registro_fonte` | cópia de leitura de um material original |
| `moc` | mapa curado |
| `trilha` | sequência orientada |
| `consulta` | vista dinâmica ou relatório |
| `template` | modelo de criação |
| `auditoria` | verificação documentada |
| `pendencia` | lacuna ou tarefa de revisão |
| `infraestrutura` | schema, vocabulário e configuração |
