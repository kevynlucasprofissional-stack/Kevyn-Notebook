## Achados relevantes

- Usar os elementos na tela projeto em lista pode ser interessante se você precisa deixar a tela projeto menor. Colocar a tool bar no topo da Workspace e o time code no rodapé cria um workflow mais eficiente. Deixe o histórico agrupado com a janela projetos e ma...
- Duplo clique na janela do projeto ou Ctrl + I abre janela de importação.
- Organizar os arquivos do Premier em pastas no painel dos projetos é uma questão importante e necessária, aplique sempre que possível. Visualizar a janela de projetos em listas pode ajudar a economizar espaço na área de trabalho. Organizar os arquivos por cores...
- Ao abrir uma sequência, haverá diversas configurações de personalização, configure esta etapa de acordo as necessidades do seu projeto. Mas não se preocupe tanto, provavelmente todas estas configurações se mantêm personalizáveis depois da sequência criada
